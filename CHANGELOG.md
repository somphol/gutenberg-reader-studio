## [Unreleased]

### Added

- Read-aloud narration (TTS) for the reader: sentence-by-sentence playback with a
  moving sentence highlight, optional word highlighting, play/pause, previous/next
  sentence controls, adjustable voice speed, system voice selection, click-to-jump
  sentences, and optional automatic page turns. Starts from the **Listen** toolbar
  button, the settings drawer, or the `L` shortcut.
- Fix: switching **3D page-turn** in settings now renders the selected reading mode
  immediately.
- Complete repository documentation: contributing guide, code of conduct, security
  policy, changelog, issue templates, and pull request template.
- A 1200 × 630 social preview card and Open Graph / Twitter metadata for link previews.
- README refresh with a consistent header, badges, and documentation index.
- `robots.txt` and `sitemap.xml` for the GitHub Pages site.
